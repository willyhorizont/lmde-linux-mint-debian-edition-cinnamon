# Simple Clock Cinnamon Applet

## Features
* Informative
* Lightweight
* Text only
* Zero config
* Zero dependencies

## Output
```
MM / 12 'months' | dd / $total_days 'days' | ddd, dd MMM yyyy | $hour24:mm:ss | $hour12:mm:ss AP
```
